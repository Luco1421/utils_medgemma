=====================================================================
EXPERIMENTO: conditioning sobre MedGemma  base (sin LoRA) vs con LoRA
=====================================================================

El conditioning M7 + la evaluacion M8 son la parte contractual (ref). El LoRA
sobre MedGemma es un EXTRA no contractual: ref dice explicitamente que a MedGemma
no se le aplica LoRA (M7), y las semillas/ranks de ref pertenecen al CNN (M2) y a
SAM-LoRA (M3b), no a M7/M8. Lo agregamos solo para comparar.

No hay sweep ni seleccion de hiperparametros. Se usa UNA config justa de LoRA y
se repite con 3 semillas. El rigor de la comparacion lo da el Wilcoxon pareado de
M8 (base vs LoRA sobre los mismos items), no el numero de configuraciones.


1) BASE sin entrenamiento = M7/M8 oficial. Las 6 ablaciones en una sola corrida
   sobre test. Generacion determinista (do_sample=False) -> NO necesita semillas.
   sbatch run_medgemma_base_full.slurm
   -> results/baseline/conditioned_base.json

2) LoRA generico, config justa, 3 semillas (array 0-2 -> seeds 42,43,44):
   - rank=8, alpha=16 (alpha=2*rank), lr=1e-4, 3 epocas, gradient accumulation 4.
   - entrena sobre train=77 con prompt generico tipo-A (imagen -> transcripcion);
     nunca ve mascaras/clases/distribuciones (sin sesgo de formato).
   - cada semilla entrena y evalua en test con el mismo protocolo A-D2.
   sbatch run_experimental_medgemma_lora_full.slurm
   -> results/lora/test_lora_seed<42..44>.json
   Para apagar W&B:
   sbatch --export=ALL,WANDB_MODE=disabled run_experimental_medgemma_lora_full.slurm

3) COMPARACION: media +/- std de los 3 seeds de LoRA, y Wilcoxon pareado de M8
   contra el base, para aislar el efecto del fine-tuning sobre el conditioning.


Notas:
- Los SLURM usan nukwa-long con 24h. Los tiempos reportables se guardan desde
  Python en training_metadata.json y en runtime de los JSON de evaluacion.
- LoRA se aplica con target_modules="all-linear" (todo el modelo, incluida la
  parte de vision). Inspeccionar la perdida en results/lora/logs/*.out o en W&B.
- Los checkpoints quedan en checkpoints/lora/seed<N>/ (regenerables).
